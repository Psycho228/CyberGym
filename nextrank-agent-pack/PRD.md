# Product Requirements Document

## 1. Продукт

Рабочее название: CyberGym.

CyberGym помогает игрокам CS2 регулярно развивать игровые навыки с помощью коротких ежедневных тренировок, прогрессии и формирования привычки.

## 2. Проблема

Игроки хотят улучшать aim, movement, spray control, game sense и дисциплину, но:

- не знают, что тренировать;
- занимаются нерегулярно;
- не видят измеримого прогресса;
- используют разрозненные видео, карты и советы;
- быстро теряют мотивацию.

## 3. Целевая аудитория

Основная:

- возраст 12–25 лет;
- игроки CS2;
- начальный и средний уровень;
- играют несколько раз в неделю;
- хотят повысить ранг;
- используют Android.

Дополнительная:

- вернувшиеся игроки;
- начинающие киберспортсмены;
- тренеры небольших команд;
- создатели обучающего контента.

## 4. Ценностное предложение

«Открой приложение, выполни короткую тренировку на сегодня и постепенно поднимай свой уровень и ранг».

## 5. Главный пользовательский цикл

1. Пользователь открывает приложение.
2. Видит тренировку дня.
3. Выполняет 3–5 упражнений.
4. Отмечает результаты.
5. Получает XP.
6. Поддерживает streak.
7. Видит прогресс.
8. Возвращается на следующий день.

## 6. Цели MVP

- проверить, готовы ли игроки регулярно выполнять ежедневные тренировки;
- добиться понятного onboarding-to-first-session;
- измерить D1 и D7 retention;
- определить наиболее востребованные типы упражнений;
- проверить мотивацию через XP, уровни и streak.

## 7. Не цели MVP

- объективно определять ранг игрока;
- анализировать все матчи;
- заменить профессионального тренера;
- поддерживать несколько игр;
- строить социальную сеть;
- создавать полноценного AI-coach.

## 8. Основные сценарии

### 8.1 Регистрация

Пользователь может:

- создать аккаунт по email;
- войти;
- восстановить доступ;
- выйти;
- удалить аккаунт.

### 8.2 Онбординг

Пользователь указывает:

- никнейм;
- текущий ранг;
- главную цель;
- доступное время в день;
- предпочитаемое время напоминания;
- часовой пояс.

Цели:

- повысить ранг;
- улучшить aim;
- улучшить movement;
- улучшить spray control;
- развить дисциплину;
- подготовиться к командной игре.

### 8.3 Главный экран

Отображает:

- приветствие;
- текущий уровень;
- XP до следующего уровня;
- streak;
- тренировку дня;
- ожидаемую длительность;
- быстрый переход к прогрессу.

### 8.4 Тренировка

Тренировка содержит:

- название;
- краткое описание;
- ожидаемую длительность;
- список упражнений;
- инструкции;
- тип результата;
- обязательность;
- порядок.

Типы упражнений MVP:

- timer;
- repetitions;
- score;
- checklist;
- external map/task;
- self-rating.

### 8.5 Завершение тренировки

После завершения:

- сохраняются результаты;
- сервер подтверждает завершение;
- начисляется XP;
- пересчитывается streak;
- проверяются достижения;
- отображается summary.

### 8.6 Прогресс

Пользователь видит:

- текущий уровень;
- общий XP;
- streak;
- число завершенных тренировок;
- календарь активности;
- динамику результатов по категориям;
- последние сессии.

### 8.7 Достижения

Примеры:

- первая тренировка;
- три дня подряд;
- семь дней подряд;
- десять тренировок;
- сто упражнений;
- новый персональный рекорд.

### 8.8 Уведомления

- напоминание о тренировке;
- предупреждение о риске потерять streak;
- поздравление с достижением;
- уведомление о новой программе.

## 9. Система прогресса

### XP

Базовая модель:

- завершение тренировки: 100 XP;
- бонус за полное выполнение: 20 XP;
- бонус за streak: ограниченный;
- achievement XP: отдельно.

Клиент не определяет итоговый XP.

### Level

Простая формула MVP:

```text
xp_required(level) = 100 * level
```

Формула может быть изменена позже через конфигурацию.

### Streak

- увеличивается при первой завершенной тренировке в локальный календарный день;
- не увеличивается повторно в тот же день;
- сбрасывается при пропуске полного календарного дня;
- рассчитывается сервером с учетом timezone пользователя.

## 10. Контент тренировок

Категории:

- warmup;
- aim;
- reaction;
- spray;
- movement;
- utility;
- game sense;
- mental;
- review.

Для MVP контент создается редактором вручную через Supabase.

## 11. Монетизация

На этапе закрытого теста монетизация отключена.

После подтверждения retention:

Free:
- одна тренировка в день;
- базовый прогресс;
- streak;
- базовые достижения.

Premium:
- персонализированные планы;
- расширенная статистика;
- дополнительные тренировки;
- история без ограничений;
- AI-рекомендации;
- специализированные программы.

## 12. Метрики

Главная метрика MVP:

- доля пользователей, завершивших минимум 3 тренировки за первые 7 дней.

Дополнительные:

- onboarding completion rate;
- first training completion rate;
- D1 retention;
- D7 retention;
- training completion rate;
- average exercises per session;
- streak 3+ rate;
- notification opt-in rate;
- crash-free users.

## 13. Acceptance criteria MVP

MVP готов к закрытому тесту, если:

- пользователь регистрируется;
- завершает онбординг;
- получает программу дня;
- выполняет тренировку;
- результат сохраняется;
- XP нельзя начислить повторно;
- streak корректно работает по timezone;
- прогресс отображается после перезапуска;
- RLS предотвращает доступ к чужим данным;
- основные события аналитики отправляются;
- приложение проходит smoke test на поддерживаемых версиях Android.

## 14. Ограничения

- Android 9+;
- интерфейс сначала на русском, строки готовы к локализации;
- portrait-first;
- сеть необходима для завершения и подтверждения тренировки;
- self-hosted Supabase;
- одна игра: CS2.
