# CyberGym — пакет документации для AI-агента

Этот каталог содержит минимальный комплект документов, необходимый для начала разработки Android-приложения на Kotlin.

## Концепция

CyberGym — мобильное приложение формата «Duolingo для киберспорта». Пользователь ежедневно получает короткую тренировочную программу по CS2, выполняет задания, зарабатывает XP, поддерживает streak и отслеживает прогресс.

## Целевая платформа

- Android
- Kotlin
- Jetpack Compose
- self-hosted Supabase
- S3-совместимое объектное хранилище

## Документы

- `AGENTS.md` — главные инструкции для AI-агента.
- `PRD.md` — продуктовые требования.
- `TDD.md` — технический дизайн.
- `DATABASE.md` — модель данных и правила безопасности.
- `schema.sql` — стартовая SQL-схема PostgreSQL.
- `BACKLOG.md` — приоритизированный backlog.
- `ANALYTICS.md` — события аналитики и продуктовые метрики.
- `ADR/0001-kotlin-compose.md` — архитектурное решение по стеку.
- `ADR/0002-supabase-direct.md` — решение использовать Supabase напрямую на MVP.
- `app-structure.txt` — рекомендуемая структура модулей и пакетов.

## Порядок работы агента

1. Прочитать `AGENTS.md`.
2. Прочитать `PRD.md` и `TDD.md`.
3. Выполнять задачи из `BACKLOG.md` по порядку.
4. Перед крупным изменением создавать ADR.
5. Не добавлять технологии и библиотеки без явной необходимости.
6. После каждой задачи обновлять документацию и тесты.

## MVP

Первая версия поддерживает только CS2 и включает:

- регистрацию и вход;
- профиль игрока;
- выбор текущего ранга и целей;
- ежедневную программу;
- выполнение тренировочной сессии;
- XP, уровень и streak;
- базовую статистику;
- достижения;
- push-напоминания;
- административное наполнение тренировок через Supabase.

## Не входит в MVP

- iOS;
- социальная сеть;
- полноценный AI-тренер;
- автоматический анализ демо-файлов;
- матчмейкинг;
- команды и кланы;
- собственный Kotlin backend;
- микросервисы;
- платные подписки на первом закрытом тесте.
