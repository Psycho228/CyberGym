# CyberGym CS2 Mapper Guide

Пошаговая инструкция для сборки первой MVP-карты CyberGym в Counter-Strike 2 Workshop Tools / Hammer.

Цель этого гайда — сделать не финальную “красивую” карту, а рабочий прототип:

- игрок открывает карту;
- выбирает упражнение;
- нажимает старт;
- проходит тренировку;
- получает понятный результат;
- вводит результат в Android-приложение CyberGym.

## 1. Что делаем в первой версии

Первая версия карты: `cybergym_training_hub`.

Внутри:

1. Центральный хаб.
2. Одна тренировочная зона `AIM100`.
3. Кнопка старта.
4. Мишени / боты / простые target-объекты.
5. Табличка с правилами.
6. Финальный экран с форматом результата.

MVP-упражнение:

```text
AIM100
Задача: уничтожить 100 целей как можно быстрее.
Результат: время прохождения + условный accuracy, если его получится посчитать.
Код для приложения: CYBERGYM-AIM100-100-SECONDS
```

Если на первом этапе сложно сделать автоматический подсчёт, допустим ручной MVP:

```text
CYBERGYM-AIM100-100-84
```

Где `84` — время прохождения в секундах, которое игрок видит на экране/таймере.

## 2. Подготовка CS2 Workshop Tools

1. Открой Steam.
2. Найди `Counter-Strike 2`.
3. Открой `Properties`.
4. Перейди в `DLC`.
5. Включи `Counter-Strike 2 Workshop Tools`.
6. Дождись установки.
7. Запусти CS2.
8. В Steam появится запуск через Workshop Tools, либо в CS2 будет доступен пункт инструментов.

Если Workshop Tools не запускаются:

- проверь, что CS2 установлен полностью;
- проверь включение DLC;
- перезапусти Steam;
- проверь свободное место на диске.

## 3. Создание addon

1. Запусти `Counter-Strike 2 Workshop Tools`.
2. Открой `Asset Browser`.
3. Создай новый addon.
4. Назови addon:

```text
cybergym_training
```

После создания появятся две важные папки:

```text
content/csgo_addons/cybergym_training/
game/csgo_addons/cybergym_training/
```

Обычно исходники карты лежат в `content`, а скомпилированные игровые файлы попадают в `game`.

## 4. Создание карты в Hammer

1. В Workshop Tools открой `Hammer`.
2. Выбери addon `cybergym_training`.
3. Создай новый файл карты.
4. Сохрани карту как:

```text
maps/cybergym_training_hub.vmap
```

Важно: сохраняй карту сразу. Hammer иногда странно ведёт себя с несохранёнными файлами.

## 5. Базовая сцена

Сначала делаем простую карту без красоты.

### 5.1. Создай пол

1. Выбери инструмент Block / Mesh.
2. Создай прямоугольный пол.
3. Примерный размер:

```text
2048 x 2048
```

4. Назначь простой материал, например серый dev-material.

### 5.2. Создай стены

Создай четыре стены вокруг пола.

Рекомендуемые размеры:

```text
толщина: 32
высота: 256-384
```

На первом этапе не делай сложную архитектуру. Наша цель — проверить тренировочную механику.

### 5.3. Создай потолок или оставь открытым

Для теста можно оставить карту открытой, но лучше сделать простой потолок, чтобы не ловить странные световые артефакты.

### 5.4. Добавь свет

Добавь entity:

```text
light_environment
```

И/или несколько обычных light-источников в комнате.

## 6. Player spawn

Добавь точку появления игрока:

```text
info_player_counterterrorist
```

Поставь её в центральном хабе.

Рекомендуемое имя:

```text
spawn_player_main
```

Если карта не запускается или игрок появляется в пустоте, почти всегда проблема в spawn point.

## 7. Центральный хаб

В хабе должно быть понятно, что это CyberGym.

Добавь:

1. Большую надпись:

```text
CYBERGYM TRAINING HUB
```

2. Малую надпись:

```text
Выбери упражнение, пройди его и введи код результата в приложении.
```

3. Проход/дверь в зону `AIM100`.

Для текста можно использовать `point_worldtext`, если он доступен в твоей версии tools, либо заменить на простые decals/модели/таблички.

## 8. Зона AIM100

Создай отдельную комнату рядом с хабом.

Рекомендуемый размер:

```text
ширина: 2048
длина: 3072
высота: 384
```

Внутри:

- позиция игрока;
- линия старта;
- кнопка старта;
- область появления целей;
- табличка с правилами.

Название зоны:

```text
zone_aim100
```

## 9. Разметка зоны AIM100

### 9.1. Позиция игрока

Создай визуальную отметку на полу.

Название:

```text
aim100_player_position
```

Текст рядом:

```text
Встань здесь перед стартом.
```

### 9.2. Кнопка старта

Добавь кнопку/entity для взаимодействия.

Возможные варианты:

- `func_button`, если доступен;
- интерактивная кнопка через prop + trigger;
- простой `trigger_multiple` как зона старта.

Рекомендуемое имя:

```text
btn_aim100_start
```

Текст рядом:

```text
START AIM100
```

### 9.3. Табличка правил

Текст:

```text
AIM100
Уничтожь 100 целей.
Запомни время прохождения.
Введи результат в CyberGym.
```

## 10. Мишени для первого MVP

Есть два пути.

### Вариант A: простые статичные мишени

Это самый простой вариант для первого прототипа.

1. Создай 10-20 target-объектов на стене.
2. Размести их на разной высоте.
3. Сделай так, чтобы игрок стрелял по ним.
4. После попадания target можно скрывать/заменять вручную через entity logic, если получится.

Плюс: быстро.

Минус: сложно честно считать 100 целей без скриптов/логики.

### Вариант B: боты

Можно сделать тренировку через ботов.

Идея:

- игрок стартует;
- боты появляются в заранее заданных точках;
- игрок убивает 100 ботов;
- время смотрит по таймеру.

Плюс: понятная CS-механика.

Минус: потребуется аккуратно настроить spawn/поведение ботов.

### Рекомендация для первой версии

Начни с варианта B, если быстро получится заспавнить ботов.

Если нет — делай вариант A и не застревай. Для CyberGym важнее проверить петлю:

```text
карта → упражнение → результат → приложение → прогресс
```

## 11. Entity naming convention

Используй понятные имена. Это сильно упростит поддержку.

```text
cg_aim100_start_button
cg_aim100_start_relay
cg_aim100_timer
cg_aim100_target_001
cg_aim100_target_002
cg_aim100_spawn_001
cg_aim100_spawn_002
cg_aim100_finish_text
cg_hub_welcome_text
```

Префикс `cg_` = CyberGym.

## 12. Логика старта упражнения

Желаемая логика:

```text
Игрок нажал START
→ показать текст "AIM100 started"
→ запустить таймер
→ включить/заспавнить цели
→ после завершения показать результат
```

Сущности:

```text
cg_aim100_start_button
cg_aim100_start_relay
cg_aim100_timer
cg_aim100_finish_text
```

Пример связей:

```text
cg_aim100_start_button
  OnPressed → cg_aim100_start_relay → Trigger

cg_aim100_start_relay
  OnTrigger → cg_aim100_timer → Enable
  OnTrigger → cg_aim100_start_text → Display
  OnTrigger → cg_aim100_targets → Enable/Spawn
```

Точные названия outputs/inputs могут отличаться в Hammer. Смысл важнее буквального имени.

## 13. Таймер

Для MVP можно использовать один из вариантов.

### Вариант A: внутриигровой round timer

Самый простой вариант:

- игрок запускает упражнение;
- смотрит время раунда;
- после 100 kills записывает время.

Минус: менее красиво.

### Вариант B: logic_timer + game_text

Более правильный вариант:

- `logic_timer` тикает каждую секунду;
- переменная/счётчик увеличивается;
- `game_text` показывает текущее время.

Минус: в CS2 entity logic может быть капризной, нужно тестировать.

### Рекомендация

Для первой карты используй round timer или простой визуальный таймер. Не упирайся в идеальный автоматический подсчёт на первом шаге.

## 14. Завершение упражнения

Желаемое завершение:

```text
100 целей уничтожено
→ показать "AIM100 COMPLETE"
→ показать формат результата
→ вернуть игрока в хаб или открыть дверь назад
```

Текст результата:

```text
AIM100 COMPLETE
Введите в CyberGym:
CYBERGYM-AIM100-100-[ВАШЕ_ВРЕМЯ]
```

Например:

```text
CYBERGYM-AIM100-100-84
```

Это не идеально, потому что игрок вводит время вручную. Но для MVP это нормально.

## 15. Как сделать результат менее читерным

На MVP не нужно пытаться идеально защититься от читов. Это pet-проект и продуктовая проверка.

Но можно улучшить:

1. Показывать код только после завершения упражнения.
2. Добавлять в код номер версии карты:

```text
CYBERGYM-AIM100-V1-100-84
```

3. Добавлять сложность:

```text
CYBERGYM-AIM100-V1-NORMAL-100-84
```

4. В приложении принимать только известные форматы.

## 16. Формат результата для Android

Рекомендуемый формат:

```text
CYBERGYM-{TASK}-{VERSION}-{DIFFICULTY}-{SCORE}-{SECONDS}
```

Пример:

```text
CYBERGYM-AIM100-V1-NORMAL-100-84
```

Расшифровка:

```text
TASK = AIM100
VERSION = V1
DIFFICULTY = NORMAL
SCORE = 100
SECONDS = 84
```

В приложении можно рассчитать:

```text
accuracy_score = score
speed_score = max(0, 120 - seconds)
xp = score + speed_score
skill = aim
```

## 17. Карта навыков CyberGym

Для MVP:

```text
AIM100 → aim
FLICK30 → aim + reaction
SPRAY30 → spray
STRAFE50 → movement
PREFIRE20 → positioning + game_sense
```

Первой делаем только:

```text
AIM100 → aim
```

## 18. Минимальный визуальный стиль

Не трать много времени на красоту в первой версии, но стиль CyberGym должен чувствоваться.

Цвета:

```text
фон: тёмный / графитовый
акцент: cyan / electric blue
опасность: red / neon red
успех: green
```

В хабе:

```text
CYBERGYM
TRAIN. MEASURE. RANK UP.
```

В AIM100:

```text
PURE AIM
100 TARGETS
NO EXCUSES
```

## 19. Компиляция карты

В Hammer:

1. Сохрани карту.
2. Нажми `Build Map`.
3. Для теста выбери fast/preview compile.
4. Дождись окончания сборки.
5. Запусти карту.

Если карта не запускается:

- проверь наличие player spawn;
- проверь, что карта сохранена в addon;
- проверь ошибки компиляции;
- проверь, нет ли дыр в мире, если используется sealed geometry;
- временно упрости карту до пола, стен, света и spawn.

## 20. Запуск карты в CS2

После компиляции попробуй открыть карту из Workshop Tools.

Если нужен запуск через консоль:

```text
map cybergym_training_hub
```

Если карта не находится, проверь фактическое имя скомпилированной карты и addon.

## 21. Тест-чеклист

Перед тем как считать карту рабочей:

- [ ] Игрок появляется в хабе.
- [ ] Есть понятное название CyberGym.
- [ ] Есть вход в AIM100.
- [ ] Есть правила упражнения.
- [ ] Кнопка старта нажимается.
- [ ] Цели/боты доступны после старта.
- [ ] Упражнение можно пройти.
- [ ] Игрок видит формат результата.
- [ ] Результат можно вручную ввести в CyberGym.
- [ ] Карта не крашится после рестарта.

## 22. Что добавить в приложение для первого теста

Минимальный экран:

```text
Workshop Training

1. Открой карту CyberGym Training Hub.
2. Пройди AIM100.
3. Введи код результата.
4. Получи XP и прогресс.
```

Поле ввода:

```text
CYBERGYM-AIM100-V1-NORMAL-100-84
```

После отправки:

```text
Результат принят
AIM +XP
Время: 84 сек
```

## 23. SQL для хранения результатов

Для приложения можно использовать такую таблицу:

```sql
create table if not exists public.workshop_results (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  task_code text not null,
  map_version text not null,
  difficulty text not null,
  score integer not null,
  seconds integer,
  raw_code text not null,
  created_at timestamptz not null default now()
);

alter table public.workshop_results enable row level security;

create policy "Users can read own workshop results"
on public.workshop_results
for select
to authenticated
using (auth.uid() = user_id);

create policy "Users can insert own workshop results"
on public.workshop_results
for insert
to authenticated
with check (auth.uid() = user_id);
```

Позже можно добавить античит-поля:

```sql
map_checksum text,
session_nonce text,
client_version text
```

## 24. Что делать после AIM100

После первой рабочей станции добавлять упражнения в таком порядке:

1. `FLICK30` — 30 быстрых целей.
2. `SPRAY30` — контроль спрея по стене.
3. `STRAFE50` — стрельба после остановки.
4. `PREFIRE20` — префаер по углам.
5. `UTILITY10` — гранаты на выбранных картах.

Не добавляй всё сразу. Каждая новая станция должна давать измеримый результат.

## 25. Главная продуктовая идея

Карта не должна быть просто “ещё одной aim map”.

Она должна быть частью CyberGym:

```text
Приложение говорит, что тренировать
→ карта даёт упражнение
→ игрок получает результат
→ приложение обновляет прогресс
→ следующий план становится персональнее
```

Это и есть отличие CyberGym от обычного трекера.

## 26. Рекомендуемый первый рабочий день

Если делать максимально прагматично:

1. Установить Workshop Tools.
2. Создать addon `cybergym_training`.
3. Создать карту `cybergym_training_hub`.
4. Сделать одну комнату.
5. Добавить spawn.
6. Добавить свет.
7. Добавить надпись CyberGym.
8. Добавить зону AIM100.
9. Добавить стартовую кнопку/триггер.
10. Добавить хотя бы 10 целей.
11. Скомпилировать.
12. Запустить.
13. Проверить, что пользователь может пройти упражнение и получить ручной код.

И только после этого улучшать визуал и автоматический подсчёт.

## 27. Если нужен mapper

Если ты будешь отдавать это человеку, который умеет Hammer, формулировка задачи такая:

```text
Нужно сделать CS2 Workshop карту CyberGym Training Hub.

MVP:
- тёмный тренировочный хаб в киберспортивном стиле;
- одна зона AIM100;
- стартовая кнопка;
- 100 целей/ботов или воспроизводимая механика уничтожения целей;
- отображение результата в формате CYBERGYM-AIM100-V1-NORMAL-100-[SECONDS];
- карта должна компилироваться и запускаться локально в CS2.

Важно:
- не делать сложную декоративную карту;
- сначала проверить тренировочную механику;
- все основные entity назвать с префиксом cg_;
- подготовить карту так, чтобы позже можно было добавить FLICK30, SPRAY30, STRAFE50.
```

## 28. Итоговая рекомендация

Первый прототип должен быть грубым, но работающим.

Хороший MVP:

```text
некрасивый, но запускается;
простая комната, но есть упражнение;
ручной результат, но он попадает в CyberGym;
мало станций, но понятна продуктовая петля.
```

Плохой MVP:

```text
красивая карта без работающего результата;
много станций без измерений;
сложная логика, которую невозможно быстро отладить;
месяц работы до первого теста.
```

Для CyberGym сейчас важнее доказать механику:

```text
персональный план → тренировка в CS2 → результат → прогресс → следующий план
```
