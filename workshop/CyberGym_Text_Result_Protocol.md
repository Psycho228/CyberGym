# CyberGym Workshop Text Result Protocol v1

Этот формат предназначен для вывода результатов прямо на итоговом экране карты CS2 Workshop и распознавания камерой Android-приложения.

## Формат экрана

Карта должна одновременно показать весь блок:

```text
CYBERGYM RESULT V1
RUN A7K29P
MAP CYBERGYM_TRAINING_HUB
EX WARMUP ATTEMPTS 40 HITS 31 ACCURACY 77.5 SCORE 74
EX AIM50 ATTEMPTS 70 HITS 51 HEADSHOTS 46 ACCURACY 72.9 SCORE 78
EX STRAFE50 ATTEMPTS 50 STOPS 42 HITS 39 SPEED 19.4 SCORE 83
END
```

Обязательные строки:

- `CYBERGYM RESULT V1` — заголовок и версия протокола;
- `RUN <id>` — уникальный идентификатор прохождения длиной 4–120 символов;
- `MAP <name>` — техническое имя карты без пробелов;
- одна строка `EX` для каждого упражнения тренировки;
- `END` — признак того, что камера видит блок целиком.

## Правила отображения

- использовать латинские заглавные буквы и арабские цифры;
- белый моноширинный текст на сплошном тёмном фоне;
- не применять анимацию, свечение, прозрачность и декоративные символы;
- выводить весь блок одновременно, не разбивать его на страницы;
- оставлять заметные интервалы между строками;
- не переводить технические ключи;
- для дробных значений использовать точку. Приложение также принимает запятую.

Чем крупнее и контрастнее символы, тем надёжнее распознавание. Игрок должен иметь возможность неподвижно смотреть на экран результатов до подтверждения в приложении.

## Коды упражнений

| Код карты | Идентификатор приложения |
| --- | --- |
| `WARMUP` | `warmup_flicks` |
| `AIM50` | `aim_headshots` |
| `SPRAY5` | `ak_spray` |
| `STRAFE50` | `counter_strafe` |

Для каждой строки используется схема `EX <exercise> <metric> <value> ...`. Поддерживаемые короткие ключи метрик: `ATT`, `HITS`, `HS`, `ACC`, `STOPS`, `SPEED`, `TIME`, `BEST`, `AVG_TIME`, `SCORE`. Полные имена (`ATTEMPTS`, `ACCURACY`, `HEADSHOTS` и другие) тоже поддерживаются.

## Проверки приложения

Приложение принимает текст только когда видит заголовок и `END`, затем проверяет наличие `RUN`, `MAP` и точное совпадение набора упражнений с открытой тренировкой. После распознавания пользователь видит редактируемую форму и сам подтверждает отправку.

Сервер продолжает принимать прежнюю структуру результатов: Android преобразует распознанный текст в JSON перед вызовом RPC. Поэтому новая SQL-миграция для OCR не требуется. Повторное использование одного `run_id` для пользователя блокируется существующей серверной проверкой.

Распознанные и отредактированные значения являются пользовательскими данными, а не защищённым от подмены античит-протоколом.

## Готовые примеры

Для проверки приложения без готовой Workshop-карты откройте [страницу тестовых результатов](text_samples/index.html) на мониторе. На ней есть дневной план и одиночные примеры для всех четырёх упражнений, полноэкранный режим и генерация нового `RUN`.
