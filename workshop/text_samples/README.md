# Примеры текстовых результатов CyberGym

Откройте [index.html](index.html) на компьютере, выберите тренировку и наведите камеру приложения на тёмный блок. Для лучшего распознавания разверните браузер на весь экран и держите телефон горизонтально или вертикально так, чтобы одновременно были видны заголовок `CYBERGYM RESULT V1` и строка `END`.

Доступные примеры:

- `daily_foundation.txt` — ежедневный план: разминка, AIM и counter-strafe;
- `practice_warmup.txt` — только разминка;
- `practice_aim50.txt` — только AIM50;
- `practice_spray5.txt` — только spray control;
- `practice_strafe50.txt` — только counter-strafe.

Набор упражнений на экране обязан точно совпадать с тренировкой, открытой в приложении. Если пользователь подтвердил результат, этот `RUN` нельзя использовать повторно. Кнопка «Новый RUN» на HTML-странице создаёт новый идентификатор без изменения метрик.

Формат для Workshop-карты описан в [CyberGym_Text_Result_Protocol.md](../CyberGym_Text_Result_Protocol.md).
