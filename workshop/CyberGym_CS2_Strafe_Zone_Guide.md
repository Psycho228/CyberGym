# CyberGym CS2 Mapper Guide: зона “Стрейфинг”

Пошаговая инструкция для создания зоны `Counter-Strafe / Стрейфинг` на карте CyberGym в Counter-Strike 2 Workshop Tools / Hammer.

Документ опирается на аналитику из файла:

```text
workshop/Стрейфинг.md
```

Главная цель зоны — проверить и тренировать навык остановки перед первым выстрелом после движения влево/вправо.

## 1. Что должна делать зона

Игрок проходит 50 попыток.

Логика одной попытки:

```text
Показать направление
→ игрок делает стрейф влево или вправо
→ появляется цель
→ игрок останавливается
→ делает первый выстрел
→ карта фиксирует скорость в момент выстрела
→ карта фиксирует попадание/промах
→ показывает короткий feedback
→ запускает следующую попытку
```

Для первого рабочего прототипа можно сделать упрощённую версию:

```text
игрок вручную запускает упражнение
→ проходит серию попыток
→ карта показывает результат/код
→ пользователь вводит код в CyberGym
```

## 2. Рекомендуемый MVP зоны

Название зоны:

```text
STRAFE50
```

Протокол:

```text
diagnostic_type: counter_strafe
protocol_version: 0.1
attempts: 50
weapon: AK-47
metric: скорость игрока в момент первого выстрела
```

Результат:

```text
Stop-shots: 38 / 50
Средняя скорость первого выстрела: 29 u/s
Влево: 18 / 25
Вправо: 20 / 25
Попадания первым выстрелом: 34 / 50
Код: CG1-38-294-18-20-K7
```

Важно: остановку и попадание лучше считать отдельно.

Плохой вариант:

```text
корректная попытка = остановился + попал
```

Хороший вариант:

```text
stop quality = скорость в момент первого выстрела
aim result = попадание или промах
```

Так приложение сможет понять, что именно проседает: movement или aim.

## 3. Подготовка в Hammer

Открой уже созданный addon:

```text
cybergym_training
```

Открой карту:

```text
maps/cybergym_training_hub.vmap
```

Если зоны ещё нет, сохрани текущую карту перед началом:

```text
File → Save
```

Рекомендация: перед большой правкой сделай копию карты:

```text
File → Save As
maps/cybergym_training_hub_strafe_wip.vmap
```

Так ты сможешь откатиться, если сломаешь логику.

## 4. Где разместить зону

Лучше сделать отдельную комнату, подключённую к центральному хабу.

Структура:

```text
Центральный хаб
  ↓
Коридор
  ↓
Комната STRAFE50
  ↓
Зона результата / выход назад
```

Примерные размеры комнаты:

```text
ширина: 2048
длина: 3072
высота: 384
```

Почему не делать слишком маленькой:

- игроку нужно место для A/D движения;
- цель должна быть на комфортной дистанции;
- должна быть читаемая линия стрельбы;
- нужно место под таблички и feedback.

## 5. Создание комнаты STRAFE50

### 5.1. Создай пол

1. В Hammer выбери инструмент создания блока/mesh.
2. Создай прямоугольный пол.
3. Размер примерно:

```text
2048 x 3072
```

4. Высота блока пола:

```text
16 или 32
```

5. Назначь простой тёмный или серый материал.

Практически:

```text
выдели пол
→ открой Material Browser
→ в поиске набери dev / gray / concrete
→ выбери нейтральный материал
→ нажми Apply или перетащи материал на поверхность
```

### 5.2. Создай стены

Сделай 4 стены вокруг комнаты.

Рекомендуемые параметры:

```text
толщина: 32
высота: 384
```

Если Hammer показывает сетку, удобнее строить по grid-size `16` или `32`.

### 5.3. Создай потолок

Для MVP можно оставить комнату открытой, но лучше сделать простой потолок:

```text
размер как у пола
толщина: 16 или 32
высота: 384
```

Потолок уменьшит странности со светом.

## 6. Свет

Добавь несколько источников света.

Простой вариант:

1. Включи Entity Tool.
2. Выбери entity `light`.
3. Поставь 2-4 источника над зоной.
4. Цвет можно сделать холодным:

```text
cyan / white-blue
```

Если используешь `light_environment`, он полезнее для открытых сцен. В закрытой комнате чаще проще поставить обычные `light`.

## 7. Игровая позиция игрока

В центре ближе к началу комнаты сделай стартовую позицию.

### 7.1. Визуальная площадка

Создай прямоугольник/плитку на полу:

```text
ширина: 384
длина: 256
```

Материал:

```text
яркий cyan / синий / контрастный dev
```

Название, если объект можно назвать:

```text
cg_strafe_player_pad
```

### 7.2. Текст над площадкой

Добавь `point_worldtext`, если он доступен.

Текст:

```text
СТАНЬ ЗДЕСЬ
```

Малый текст:

```text
Смотри прямо. Двигайся A/D по команде.
```

Если `point_worldtext` неудобен, используй временную табличку/декаль/геометрию. На MVP текст можно заменить простыми стендами.

## 8. Линия стрейфа

Игрок должен понимать, куда двигаться.

Сделай на полу горизонтальную линию:

```text
← A        CENTER        D →
```

Практически:

1. Создай тонкие прямоугольные полосы на полу.
2. Левая полоса — красная/розовая.
3. Правая полоса — cyan/синяя.
4. В центре — белая/серая отметка.

Названия:

```text
cg_strafe_left_lane
cg_strafe_center_mark
cg_strafe_right_lane
```

Рекомендуемый размер:

```text
левая линия: 512 x 32
правая линия: 512 x 32
центральная отметка: 64 x 64
```

Игрок должен стоять на центре и делать короткий стрейф в сторону.

## 9. Зона цели

Цель должна появляться перед игроком, примерно на уровне головы.

### 9.1. Стена целей

На дальней стене сделай target wall.

Примерная дистанция от игрока:

```text
1024-1536 units
```

Высота зоны целей:

```text
примерно на уровне головы игрока
```

### 9.2. Target positions

Сделай 5-7 позиций для целей:

```text
cg_strafe_target_pos_001
cg_strafe_target_pos_002
cg_strafe_target_pos_003
cg_strafe_target_pos_004
cg_strafe_target_pos_005
```

Расположение:

```text
лево-низ
лево-верх
центр
право-верх
право-низ
```

Не делай цели слишком мелкими на первом прототипе. Нам нужно диагностировать остановку, а не устроить Kovaak на минималках.

## 10. Кнопка старта

### 10.1. Создай кнопку

Если доступен `func_button`:

1. Создай небольшой блок на стене или стойке.
2. Преврати его в `func_button`.
3. Назови:

```text
cg_strafe_start_button
```

Текст рядом:

```text
START STRAFE50
```

Если `func_button` в твоей сборке неудобен, сделай `trigger_multiple`:

1. Создай невидимый trigger-объём перед табличкой старта.
2. Игрок входит в него.
3. Это считается запуском.

Название:

```text
cg_strafe_start_trigger
```

### 10.2. Добавь relay старта

Создай entity:

```text
logic_relay
```

Название:

```text
cg_strafe_start_relay
```

Идея:

```text
кнопка/trigger
→ cg_strafe_start_relay
→ сброс состояния
→ запуск первой попытки
```

## 11. Табличка правил

В начале зоны добавь большой текст:

```text
STRAFE50
```

Ниже:

```text
50 попыток
1. Смотри на цель.
2. Двигайся в указанную сторону.
3. Остановись counter-strafe.
4. Сделай первый выстрел.
```

Ещё ниже:

```text
Считается скорость в момент первого выстрела.
Попадание и остановка оцениваются отдельно.
```

Это важно: игрок должен понять, что задача не просто “попасть”, а выстрелить после правильной остановки.

## 12. Направление попытки

Для MVP чередуем направления:

```text
попытка 1: LEFT / A
попытка 2: RIGHT / D
попытка 3: LEFT / A
попытка 4: RIGHT / D
...
```

Так проще:

- не нужно вычислять направление относительно взгляда;
- игрок понимает протокол;
- результаты лево/право легко сравнивать;
- меньше мест, где скрипт может ошибиться.

В комнате нужны два крупных индикатора:

```text
LEFT / A
RIGHT / D
```

Названия:

```text
cg_strafe_left_text
cg_strafe_right_text
```

На каждой попытке скрипт или logic должен показывать только нужное направление.

## 13. Feedback после попытки

После первого выстрела игроку нужно показать короткий feedback:

Хороший:

```text
GOOD STOP
Speed: 18 u/s
Hit: yes
```

Плохой:

```text
TOO EARLY
Speed: 92 u/s
Hit: no
```

Feedback должен быть быстрым, 0.5-1.0 секунды, чтобы не ломать ритм.

Названия:

```text
cg_strafe_feedback_text
cg_strafe_result_text
```

## 14. Первый прототип без скрипта

Если ты пока собираешь карту руками и не готов подключать `cs_script`, сделай manual-MVP.

Что будет:

1. Комната STRAFE50.
2. Площадка игрока.
3. Линия A/D.
4. Стена целей.
5. Кнопка старта.
6. Текстовые инструкции.
7. Таймер по раунду или визуальный таймер.
8. Игрок сам считает серию/время.

Это звучит “тупо”, но это полезный первый этап: ты проверишь геометрию, дистанции, комфорт и UX зоны.

Manual result code:

```text
CYBERGYM-STRAFE50-V0-MANUAL-[GOOD]-[SECONDS]
```

Пример:

```text
CYBERGYM-STRAFE50-V0-MANUAL-37-140
```

## 15. Скриптовая версия зоны

Скрипт нужен, чтобы считать:

- попытки;
- направление;
- первый выстрел;
- скорость игрока;
- попадание/промах;
- итоговый код.

Минимальное состояние:

```ts
let attempt = 0
let attemptActive = false
let shotRecorded = false

let validShots = 0
let hitShots = 0
let speedSum = 0

let leftAttempts = 0
let leftValid = 0

let rightAttempts = 0
let rightValid = 0

const TOTAL_ATTEMPTS = 50
const STOP_THRESHOLD = 35
```

Порог `35` здесь примерный. Его нужно калибровать. Не считай его финальным стандартом.

## 16. Где хранить скрипт

В addon создай папку для скриптов, например:

```text
content/csgo_addons/cybergym_training/scripts/
```

Файл:

```text
counter_strafe.ts
```

Или, если твоя версия Workshop Tools использует другую структуру для `cs_script`, придерживайся структуры, которую создаёт Asset Browser / Script Editor.

Важно: в CS2 Workshop Tools структура скриптов и привязка к map logic может отличаться между версиями. Поэтому сначала сделай маленький test script, который просто выводит текст при старте карты.

## 17. Псевдокод скрипта

Это не гарантированно готовый copy-paste код под твою версию tools, а архитектурная заготовка.

```ts
type Direction = "left" | "right"

let attempt = 0
let attemptActive = false
let shotRecorded = false

let validShots = 0
let hitShots = 0
let speedSum = 0

let leftAttempts = 0
let leftValid = 0

let rightAttempts = 0
let rightValid = 0

const TOTAL_ATTEMPTS = 50
const STOP_THRESHOLD = 35

function currentDirection(): Direction {
  return attempt % 2 === 0 ? "left" : "right"
}

function startTest() {
  attempt = 0
  validShots = 0
  hitShots = 0
  speedSum = 0
  leftAttempts = 0
  leftValid = 0
  rightAttempts = 0
  rightValid = 0

  startAttempt()
}

function startAttempt() {
  if (attempt >= TOTAL_ATTEMPTS) {
    finishTest()
    return
  }

  attemptActive = true
  shotRecorded = false

  const direction = currentDirection()
  showDirection(direction)
  spawnTarget()
}

function onFirstShot(player: any) {
  if (!attemptActive || shotRecorded) return

  shotRecorded = true

  const velocity = player.GetAbsVelocity()
  const horizontalSpeed = Math.sqrt(
    velocity.x * velocity.x + velocity.y * velocity.y
  )

  const direction = currentDirection()
  const valid = horizontalSpeed <= STOP_THRESHOLD

  speedSum += horizontalSpeed

  if (direction === "left") {
    leftAttempts++
    if (valid) leftValid++
  } else {
    rightAttempts++
    if (valid) rightValid++
  }

  if (valid) validShots++

  showAttemptFeedback(direction, horizontalSpeed, valid)
  finishAttempt()
}

function onTargetHit() {
  if (!attemptActive || !shotRecorded) return
  hitShots++
}

function finishAttempt() {
  attemptActive = false
  attempt++
  despawnTarget()

  // Небольшая пауза перед следующей попыткой.
  scheduleNextAttempt()
}

function finishTest() {
  const averageSpeed = Math.round((speedSum / TOTAL_ATTEMPTS) * 10)
  const code = makeResultCode({
    validShots,
    averageSpeed,
    leftValid,
    rightValid,
  })

  showFinalResult(code)
  saveResult(code)
}
```

## 18. Как связать карту и скрипт

Общая схема:

```text
cg_strafe_start_button
→ вызывает startTest()

OnGunFire
→ вызывает onFirstShot(player)

OnBulletImpact / damage по target
→ вызывает onTargetHit()
```

Практически в Hammer:

1. Создай entity, которая будет отвечать за script logic.
2. Назови её:

```text
cg_strafe_script
```

3. В свойствах entity найди поле, связанное со скриптом.
4. Укажи файл:

```text
counter_strafe.ts
```

5. На кнопке старта добавь output:

```text
OnPressed → cg_strafe_script → startTest
```

Если в твоей версии Hammer нельзя напрямую вызвать функцию таким способом, используй промежуточный `logic_relay` или тот механизм вызова script input, который доступен в tools.

## 20. Как сделать цели

Для первого прототипа есть три уровня сложности.

### Уровень 1: неподвижные targets

Самый простой.

```text
цель стоит на стене
игрок стреляет
скрипт/логика считает попадание
```

Подходит для проверки counter-strafe.

### Уровень 2: случайная позиция

На каждую попытку цель появляется в одной из 5 позиций.

Это лучше, потому что игрок не стреляет в одну точку.

### Уровень 3: короткое окно реакции

Цель появляется на 1-2 секунды.

Если игрок слишком долго стоит, попытка считается проваленной.

Это уже второй этап, не нужно делать сразу.

## 21. Правильная дистанция и размеры

Начальные значения:

```text
дистанция до цели: 1024-1536 units
ширина линии стрейфа: 1024 units
размер цели: средний, хорошо видимый
оружие: AK-47
попытки: сначала 10, потом 50
```

Почему сначала 10:

- быстрее тестировать;
- легче увидеть ошибки state machine;
- меньше раздражения при отладке;
- быстрее компиляции/проверка сценария.

Когда 10 попыток работают стабильно, меняй на 50.

## 22. Калибровка STOP_THRESHOLD

Не выбирай порог “на глаз” как финальный.

Для первой отладки можно поставить:

```text
STOP_THRESHOLD = 35
```

Потом провести тест:

1. Сделай 20 идеальных counter-strafe выстрелов.
2. Запиши скорости.
3. Сделай 20 ранних выстрелов до остановки.
4. Запиши скорости.
5. Посмотри диапазоны.
6. Выбери порог, который отделяет хорошие остановки от плохих.

Версионируй протокол:

```text
STRAFE50_V01_THRESHOLD_35
```

Если потом изменишь порог, это уже новая версия:

```text
STRAFE50_V02_THRESHOLD_30
```

## 23. Result code

Рекомендуемый короткий код:

```text
CG1-{valid}-{avgSpeed10}-{leftValid}-{rightValid}-{checksum}
```

Пример:

```text
CG1-38-294-18-20-K7
```

Где:

```text
CG1 = версия протокола
38 = корректные stop-shots из 50
294 = средняя скорость x10, то есть 29.4 u/s
18 = корректные остановки влево из 25
20 = корректные остановки вправо из 25
K7 = checksum от предыдущих полей
```

Для более читаемого формата можно использовать:

```text
CYBERGYM-STRAFE50-V1-38-294-18-20-K7
```

Но для ручного ввода лучше короткий код.

## 24. Финальный экран

В конце теста покажи:

```text
CYBERGYM COUNTER-STRAFE TEST

Результат: 76 / 100

Stop-shots: 38 / 50
Средняя скорость: 29.4 u/s

Влево: 18 / 25
Вправо: 20 / 25

```

Сделай этот экран крупным. Игрок должен без скриншота спокойно переписать код.

## 25. UX зоны

Зона должна быть ритмичной.

Хороший ритм:

```text
направление
→ движение
→ цель
→ первый выстрел
→ feedback
→ следующая попытка
```

Плохой ритм:

```text
долго ждать
непонятно, куда идти
цель слишком мелкая
feedback исчезает слишком быстро
код результата трудно прочитать
```

## 26. Визуальный стиль CyberGym

Для зоны STRAFE50 я бы сделал стиль “технический полигон”.

Цвета:

```text

центр: белый/серый
лево: neon red / magenta
право: cyan / electric blue
успех: green

```

Тексты:


## 27. Как тестировать в Hammer/CS2

После сборки:

1. Запусти карту.
2. Проверь, что игрок появляется в хабе.
3. Дойди до STRAFE50.
4. Нажми Start.
5. Проверь, что первая попытка стартует.
6. Сделай стрейф влево.
7. Остановись.
8. Выстрели.
9. Проверь feedback.
10. Повтори вправо.
11. Проверь, что направления чередуются.
